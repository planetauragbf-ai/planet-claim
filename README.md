# Planet’Claim — suivi des sinistres

Application de suivi des sinistres de transport de vin (Planet Aura).

- **Site** : Netlify (publie le dossier `public/` à chaque modification de `main`)
- **Base, fichiers, comptes** : Supabase, région Paris — schéma et règles de sécurité dans `supabase/schema.sql`
- **Mise en place pas à pas** : [GUIDE.md](GUIDE.md)

Aucune donnée client ne doit être versionnée ici (le fichier HTML d’origine et les sauvegardes JSON sont exclus par `.gitignore`).
