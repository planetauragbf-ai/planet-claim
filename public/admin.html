Importer des données

1. Dossiers d’origine : choisissez le fichier HTML exporté depuis claude.ai (Suivi_des_sinistres.html). Les dossiers embarqués sont ajoutés à la base (ceux qui existent déjà ne sont pas écrasés).

2. Sauvegarde JSON : restaure un fichier produit par « Exporter » ci-dessous (ou une migration préparée par Claude).

3. Pièces jointes : sélectionnez les fichiers fournis avec la migration (leur nom, du type 37a2b5….pdf, ne doit pas être modifié). Ceux déjà présents sont ignorés.

Sauvegarde

Télécharge toute la base (hors fichiers joints) au format JSON. À conserver dans un endroit sûr (données personnelles de clients).
